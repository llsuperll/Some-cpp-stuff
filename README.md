# TOML Car Info Converter

![C++](https://img.shields.io/badge/C%2B%2B-23-blue)
![CMake](https://img.shields.io/badge/CMake-3.12%2B-green)
![Compiler](https://img.shields.io/badge/Compiler-Clang%2B%2B-orange)

Консольное приложение на C++, предназначенное для сериализации и десериализации структуры `Car` в формат TOML и обратно. Проект поддерживает работу с различными типами строк (`std::string`, нуль-терминированные `char*` и `char*` с явным указанием размера).

## 🚀 Основные возможности

*   **Сериализация в TOML (`to_toml`)**:
    *   Преобразование структуры `Car` (бренд, владелец, пробег) в строку формата TOML.
    *   Поддержка трех вариантов возвращаемого значения: `std::string`, `char*` (с нуль-терминатором) и `std::pair<const char*, size_t>`.
*   **Десериализация из TOML (`to_struct`)**:
    *   Парсинг строки TOML и создание объекта `Car`.
    *   Поддержка трех вариантов входных данных: `std::string`, `char*` (нуль-терминированный) и `std::pair<const char*, size_t>`.
    *   Валидация данных: проверка бренда автомобиля с помощью регулярного выражения (разрешены только буквы, пробелы и дефисы, до 16 символов).
*   **Интерактивный интерфейс**:
    *   Удобное текстовое меню для выбора операций (от 1 до 7).
    *   Обработка ошибок ввода (неверный тип данных, преждевременный конец файла `EOF`).
    *   Безопасная работа с памятью при выделении и освобождении `char*`.

## 📂 Структура проекта

```text
.
├── car.hpp        # Структура Car и валидация бренда
├── func.hpp       # Объявления функций преобразования TOML
├── func.cpp       # Реализация логики парсинга и сериализации
├── ui.hpp         # Объявления для пользовательского интерфейса
├── ui.cpp         # Реализация консольного меню и ввода
├── main.cpp       # Точка входа, цикл обработки исключений

```

# Printed Circuit Board (PCB) Management System

![C++](https://img.shields.io/badge/C%2B%2B-20-blue)
![Tests](https://img.shields.io/badge/Tests-Catch2%20%7C%20Custom-green)

Этот репозиторий содержит реализацию системы управления контактами на печатной плате (Printed Circuit Board) на языке **C++**. Проект позволяет моделировать контакты, создавать связи между ними, рассчитывать задержки сигналов, а также выполнять поиск и сортировку элементов.

## 🚀 Основные возможности

*   **Управление контактами (`Contact`)**:
    *   Хранение координат (X, Y) и типа контакта (`IN` / `OUT`).
    *   Создание связей между контактами (с проверкой типов и занятости).
    *   Расчет Евклидова расстояния от начала координат.
    *   Расчет задержки сигнала между соединенными контактами.
    *   Перегрузка операторов (`>>`, `<<`, `<=>`) для ввода/вывода и сравнения.
*   **Управление печатной платой (`PCBoard`)**:
    *   Динамическое добавление и удаление контактов (с автоматическим расширением массива).
    *   Запрет на размещение двух контактов в одних и тех же координатах.
    *   Создание и разрыв связей между контактами по их индексам.
    *   Сортировка контактов по удаленности от центра платы.
    *   Поиск наиболее удаленной пары соединенных контактов.
*   **Логирование (`Logger`)**:
    *   Ведение логов в файл `logs.txt` (используется в кастомных тестах).
*   **Документация и тесты**:
    *   Поддержка генерации документации через **Doxygen**.
    *   Модульные тесты с использованием фреймворка **Catch2**.
    *   Кастомные тесты с логированием результатов.
